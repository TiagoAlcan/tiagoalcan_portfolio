# Documentação do portfólio

Estes documentos foram escritos **antes** do código do site. Eles registram o que o portfólio precisa comunicar, como ele deve parecer e como será construído.

| Documento | Responde a |
|---|---|
| [00 · Visão e ideação](00-visao-e-ideacao.md) | Para quem é o site, o que ele diz e por quê |
| [01 · Design system](01-design-system.md) | Como ele parece: cores, tipografia, componentes, movimento |
| [02 · System design](02-system-design.md) | Como ele é construído: arquitetura, rotas, dados, deploy |
| [03 · Design patterns](03-design-patterns.md) | Como o código é organizado e quais padrões são obrigatórios |
| [04 · Modelo de conteúdo](04-modelo-de-conteudo.md) | Que conteúdo existe, em que formato, e o que falta produzir |
| [ADRs](adr/) | Por que cada decisão estrutural foi tomada |

## Ordem de leitura

Quem vai revisar o conceito lê o `00` e o `01`. Quem vai implementar lê do `02` ao `04` e consulta os ADRs quando quiser entender uma escolha.

## Pendências que bloqueiam a implementação

Estão listadas na seção "Lacunas" do [04](04-modelo-de-conteudo.md#lacunas). As três principais:

1. Fornecer a foto em alta resolução.
2. Validar as capturas e os vídeos dos projetos antes de entrarem no site.
